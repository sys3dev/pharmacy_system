# نظام ادارة الصيدليات ونقاط البيع (pharmacy management & POS system)
نظام متكامل لادارة الصيدليات، المبيعات، والمخزون، مدعوم بقارئ الباركود ونظام تنبيهات ذكي لمتابعة الادوية.
### ابرز مميزات النظام: 
** نقاط البيع السريعة(POS): دعم البحث السريع وقراءة الباركود لاتمام الفواتير بدقة.
** ادارة المخزون والادوية: متابعة الكمبات المتوفرة، وتةاريخ الصلاحية، وتصنيفات الادوية.
** نظام التنبيهات (notifications): اشعارات تلقائية عند انخفاض مخزون اي دواء او قرب انتهاء صلاحيته.
** ادارة المستخدمين: واجهة تسجيا دخول امنة. 
### معاينة واجهات النظام: 
1. شاشة تسجيل الدخول: (LOGIN.PNG)[LOGIN]
2. واجهة قراءة الباركود ونقاط البيع: (barcode.png)[Barcode]
3. ادارة الادوية والمخزون: (drugs.png)[Drugs]
4. نظام التنبيهات والاشعارات:(notification.png)[Notifications]
